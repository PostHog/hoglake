# Sampo

Changesets for the next release live in `changesets/`, one markdown file
per change; `sampo release` (run by `.github/workflows/release.yml`)
consumes them into version bumps and `CHANGELOG.md` entries.

- How to write one: [CONTRIBUTING.md § Adding a changeset](../CONTRIBUTING.md#adding-a-changeset)
- The release flow: [AGENT.md § Versioning](../AGENT.md#versioning)
- Sampo's documentation: https://github.com/bruits/sampo/blob/main/crates/sampo/README.md
